## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Gemini API

## Installation

```bash
npm install
```

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_api_key
```

Run locally:

```bash
npm run dev
```
